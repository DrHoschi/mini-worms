# Dokumentation

Die verbindliche Projektbasis besteht aus **MW-00 bis MW-05**, Stand 24.08.2026, Status **FROZEN**.

Dieses Verzeichnis ergänzt die FROZEN-Dokumente nur um arbeitsnahe Repository-Dokumentation. Es ersetzt oder ändert keine fachliche Definition aus MW-00 bis MW-05.

## Struktur

- `baseline/` – Kennzeichnung der verbindlichen FROZEN-Basis
- `P000/` – Arbeits- und Statusdokumentation für P000

Für fachliche Konflikte gilt weiterhin die Ownership aus MW-00: Gameplay in MW-01, technische Definitionen in MW-02, Content in MW-03, Roadmap/Scope in MW-04 und Grundentscheidungen in MW-05.
